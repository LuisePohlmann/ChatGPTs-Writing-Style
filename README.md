# A Comparative Analysis of Language in Scientific Papers Written by ChatGPT and Human Authors

## Project Description
In anecdotal evidence on X, words like delve, safeguard, robust, and demystify are certain signs of LLM’s writing (Graham, 2024). 
However, current research shows that it is not as easy to tell the difference as one may think. This repository contains code to comapre 
scientific abstracts from 2015 to ChatGPT generated abstracts linguistically. Points of Comparison include word choice, sentence length, 
distribution of verbs and nouns, and number of boosters and hedges.

## Usage
To perform the analysis run `Data_Analysis_ChatGPT's_Writing_Style.ipynb`.
